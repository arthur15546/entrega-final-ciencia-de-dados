# Projeto de ciência de dados

Este projeto analisa dados sintéticos de hotéis com notebooks de exploração, estatística, modelagem de banco de dados e visualização.

## Estrutura

- `dados/`: fontes de dados em formato JSONL.
- `notebooks/`: exploração, estatística, banco de dados e visualização.
- `banco/`: bancos de dados e diagrama entidade-relacionamento.
- `dashboard/`: aplicativo Streamlit e dados pré-computados.
- `diario_de_campo/`: registros e reflexões do projeto.
- `relatorio_executivo/`: relatório executivo em Markdown e PDF.

O diretório `.venv/`, as capturas de tela e o guia completo são arquivos locais e não fazem parte do repositório.
