# Projeto de ciência de dados

Este projeto analisa dados sintéticos de hotéis com notebooks de exploração,
estatística, modelagem de banco de dados e visualização. Consulte o
[guia completo do projeto](GUIA_COMPLETO_DO_PROJETO.md) para conhecer os dados,
a metodologia, os resultados, as limitações e como executar cada etapa.

## Estrutura

- `dados/`: fontes de dados em formato JSONL.
- `notebooks/`: exploração, estatística, banco de dados e visualização.
- `banco/`: bancos de dados, diagrama entidade-relacionamento e captura de tela.
- `dashboard/`: aplicativo Streamlit e dados pré-computados.
- `diario_de_campo/`: registros e reflexões do projeto.
- `relatorio_executivo/`: relatório executivo em Markdown e PDF.
- `GUIA_COMPLETO_DO_PROJETO.md`: documentação detalhada do projeto.

O diretório `.venv/` é local e não faz parte do repositório.
